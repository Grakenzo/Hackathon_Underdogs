Ten IT support job ads were collected manually from Seek (Brisbane, September 2026) and saved in ads/it-support/. Those ads were passed to a language model with instructions to extract only what appeared in them: unfamiliar terms with plain-English explanations, requirements stated as essential, requirements stated as preferred, and preparation steps. Counts were tallied across the ten ads. The output is src/data/it-support.json, which the app reads directly. No model call happens at runtime — the extraction ran once, offline, so the app is fast and returns the same answer every time. Explanations were written for a newcomer audience on top of the extracted facts.
